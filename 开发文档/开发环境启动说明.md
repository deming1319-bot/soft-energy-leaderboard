## 2. 标准启动顺序

### 2.1 启动 MySQL

首选 Docker（目标版本 MySQL 8.4）：

```powershell
cd E:\soft-energy-leaderboard
docker compose up -d mysql
docker compose ps
```

默认开发连接为端口 `3307`、数据库 `soft_energy_dev`、用户 `softenergy`。如需改密码，复制 `.env.example` 为 `.env`，只在本机填写；`.env` 不得提交。

本轮 Docker Hub 网络不可达，因此实际联调临时使用电脑已有 MySQL 8.0.45 二进制，在 `runtime/mysql-data` 建立了独立数据目录并监听 3307。它没有使用、修改或读取原有 3306 数据。正式开发与阿里云生产仍以 MySQL 8.4 为准。

### 2.2 启动后端

PowerShell 中必须显式切到 JDK 21：

```powershell
cd E:\soft-energy-leaderboard\backend
$env:JAVA_HOME='D:\Java\JDK-21\jdk-21.0.11+10'
$env:Path="$env:JAVA_HOME\bin;$env:Path"
mvn spring-boot:run
```

首次启动会由 Flyway 自动建表，并在开发环境写入一个管理员、3 道示例题和示例榜单数据。

### 2.3 启动管理端

```powershell
cd E:\soft-energy-leaderboard\admin-web
pnpm install
pnpm dev
```

浏览器打开 `http://localhost:5173`。

### 2.4 打开微信小程序

1. 打开微信开发者工具；
2. 导入目录 `E:\soft-energy-leaderboard\miniapp`；
3. `project.config.json` 已写入正式 AppID；开发环境仍允许模拟身份，正式联调必须在服务器配置对应 AppSecret；
4. 首次安装依赖后在 `miniapp` 目录执行 `pnpm build:npm`，脚本会跨平台生成 `miniprogram/miniprogram_npm`；当前工作区已生成；
5. 开发工具当前已设置 `urlCheck=false`，本地 API 为 `http://127.0.0.1:8081/api/v1`；真机调试时必须替换为已备案的 HTTPS API 域名。

## 4. 常见问题

- 管理端提示无法连接服务：先检查 8081 健康接口，再检查 MySQL 3307 是否监听。
- Maven 报 Java 版本错误：全局 Maven 当前可能使用 JDK 17，必须在当前 PowerShell 先设置 `JAVA_HOME`。
- 微信开发者工具 CLI 报“服务端口已关闭”：这只影响命令行自动打开/构建，不影响手动导入项目；可在“设置 -> 安全设置”中开启服务端口。
- Docker 拉取 MySQL 超时：属于镜像网络问题，不要把数据库临时改成 SQLite/H2；恢复网络后继续使用 `compose.yaml`。

## 5. 数据安全

- 小程序用户使用独立微信身份映射，提交记录由 `user_id` 与 `activity_id` 双重归属；
- 手机号设计为 AES-GCM 加密密文加 HMAC 检索摘要，列表仅返回脱敏号码；
- 管理员 JWT 与学员 JWT 使用不同角色，不做账号绑定；
- 标准答案不会出现在小程序题目接口中，按揭晓规则决定是否出现在提交结果中。
