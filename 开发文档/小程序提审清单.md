- [ ] 运营主体全称、统一社会信用代码或个人主体信息；

- [ ] 与实际内容匹配的服务类目及必要资质；
- [ ] APP 备案号；
- [ ] 若计划发布宗教教义、宗教知识或师门讲解，取得所在地主管部门书面确认与适用许可；
- [ ] 客服微信/客服能力可用账号；
- [ ] iOS、Android 真机各至少一台，两个不同微信测试账号。

## 三、微信公众平台配置

- [x] 将真实 AppID 写入 `miniapp/project.config.json`；
- [ ] 在“开发管理”配置 `request` 合法域名，必须是 HTTPS，不能带路径；
- [ ] 在平台生成并发布隐私保护指引，声明内容必须与代码一致：OpenID、修习名、答案、成绩、提交时间、举报与处理记录；
- [ ] 在 `miniapp/miniprogram/config/compliance.ts` 写入真实主体、联系人、地址和 APP 备案号；
- [ ] 不声明当前未调用的手机号、头像、位置、通讯录和相册权限；
- [ ] 配置服务器 AppID/AppSecret，并确认 `WECHAT_MOCK_ENABLED=false`、`WECHAT_CONTENT_SECURITY_ENABLED=true`；
- [ ] 将 `miniapp/miniprogram/config/runtime.ts` 的正式 API 占位地址替换为真实域名；
- [ ] 执行 `cd miniapp && pnpm check:release`，结果必须为通过；
- [ ] 生产数据库使用空库，`DEMO_DATA_ENABLED=false`，管理员密码和所有密钥均替换。
