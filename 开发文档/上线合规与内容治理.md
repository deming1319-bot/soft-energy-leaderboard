# 上线合规与内容治理

> 更新日期：2026-08-07  
> 适用范围：微信小程序、管理系统、后端服务与正式题库。

## 1. 首版发布边界

首个正式版本统一定位为“中华传统文化与经典哲思学习答题”。可发布分类为经典阅读、经典哲思、生活实践和传统文化。

在运营主体取得适用资质并完成主管部门书面确认前，首版不得发布宗教教义、宗教教育、讲经讲道、师门传法、修炼指导、宗教仪式、招生、募捐或引导参加宗教活动的内容。后台会拦截待资质分类和明显风险表述；历史待确认分类不会进入小程序公开接口。

## 2. 反馈与举报闭环

小程序入口包括：

- “我的修习 -> 反馈与举报”；
- 题目详情的“举报内容”；
- 榜单昵称旁的“举报”；
- 答题结果页的“申请评分复核”；
- 隐私中心的“反馈与举报”。

反馈类型包括违法不良信息、侵权投诉、昵称不当、题目内容、评分申诉、隐私问题和其他反馈。用户可以查看待处理、处理中、已办结和已驳回状态及处理回复。

管理端“反馈与举报”页面负责受理。管理员可填写处理说明；对昵称举报可同时重置昵称或停用账号。所有处理操作进入审计日志。普通反馈承诺在 7 个工作日内给出结果，运营人员应在看到违法内容后优先处置。

## 3. 账号注销与数据删除

注销成功时立即执行：

1. 删除微信 OpenID、昵称、协议同意记录和其他账号资料；
2. 删除该用户全部原始答案、标准化答案、匹配要点、复核备注和客户端请求标识；
3. 删除该用户提交或针对该用户的举报记录；
4. 使旧令牌无法继续读取个人数据；
5. 仅对已经进入冠军或亚军榜的单场最佳成绩生成匿名快照。

匿名快照只包含活动、`已注销用户`、荣誉等级和排序时间，不包含原用户 ID，不允许跨活动关联。生产备份最长保存 30 日并自动轮换，备份期间只能用于灾难恢复。

## 4. 正式资料与发布门禁

以下信息配置在 `miniapp/miniprogram/config/compliance.ts`，不得使用占位值上传：

- 运营主体全称；
- 隐私联系人；
- 联系电话或邮箱；
- 联系地址；
- APP 备案号。

项目已写入格式有效的正式 AppID；还必须在服务器配置对应 AppSecret、备案 HTTPS API 域名和微信 request 合法域名，并在微信公众平台发布与代码一致的隐私保护指引。正式环境必须关闭模拟微信登录、开启微信内容安全检测、关闭演示数据并更换管理员密码及全部密钥。

执行 `cd miniapp && pnpm check:release`。只要主体、备案、AppID、域名或合规页面任一项缺失，命令必须失败。

发布门禁还会检查项目 JSON 是否可解析、AppID 格式、`__usePrivacyCheck__`、隐私授权按钮与状态查询、协议版本一致性、首页备案展示、WXML 原生标签与闭合关系，以及小程序目录是否达到 2MB 主包风险线。正式微信登录不发送开发模拟所需的随机设备标识。

微信官方操作参考：

- [用户隐私保护指引填写说明](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/)
- [小程序网络与服务器域名要求](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)
- [小程序备案操作指引](https://developers.weixin.qq.com/miniprogram/product/record_guidelines.html)
