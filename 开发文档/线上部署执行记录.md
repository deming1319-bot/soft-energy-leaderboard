## 8. 下一步恢复入口

如果部署中断，先阅读本文件，再执行以下只读检查：

```bash
systemctl is-active jenkins nginx mysqld
ss -lntp | grep -E ':(80|443|8080|8081|3306|33060)\b' || true
test -f /root/soft-energy-db.env && stat -c '%a %U:%G %n' /root/soft-energy-db.env
test -d /opt/soft-energy && find /opt/soft-energy -maxdepth 2 -printf '%M %u:%g %p\n' | sort
```

不得执行 `cat /root/.my.cnf` 或 `cat /root/soft-energy-db.env` 后把输出发送到聊天工具。
