## 1. 已完成范围

- 独立管理员登录、JWT 鉴权与退出；

- 题目草稿、编辑、发布、提前截止；
- 题目分类、作答次数、两行精确标准答案、默认发布后12小时与指定日期时间两种截止模式；
- 全部答题记录、结果筛选、人工复核；
- 截止前榜单锁定、截止后冠军榜与亚军榜；
- 学员档案、参与/获奖统计与手机号脱敏展示；
- 关键管理操作审计；
- 反馈与举报管理：筛选、处理回复、昵称重置、账号停用和操作审计；
- 测试中心：创建/切换独立测试学员，模拟查看题目、作答、即时判定、答案揭晓和榜单；

- 测试中心提交复用正式小程序业务接口，并同步进入总览、学员档案、答题记录和排行；
- 桌面端与 390px 手机宽度响应式适配。

### 微信小程序

- 首次进入先阅读并主动同意用户协议与微信隐私保护指引，再执行 `wx.login`；

- 正式微信登录只提交登录凭证和协议版本，本地随机设备标识仅在开发模拟登录时发送；
- 开发环境支持按设备 ID 生成稳定模拟微信身份，正式/体验环境未配置 HTTPS API 时主动阻止进入；
- 首次设置及后续修改修习名，并明确说明其在截止榜单中的公开范围；
- 今日题目、进行中/未开始/已结束状态；
- 题目详情、倒计时、答案输入、重复提交保护；
- 提交后即时反馈：仅忽略表情，完全一致为冠军，仅上下联整体颠倒为亚军，其他情况不入榜；
- 截止前标准答案与榜单锁定；
- 截止后冠军/亚军双榜，按首次达到等级的时间排序；
- 个人修习档案、参与次数、获奖次数和最近记录；
- 隐私中心、个人信息清单、用户协议、资料更正、微信客服和账号注销；
- 题目举报、榜单昵称举报、评分申诉、隐私请求、处理进度和处理回复；
- 注销后删除身份和原始答题内容、旧令牌失效，榜单仅保留单场不可关联匿名荣誉快照；
- 首版公开内容限制为中华传统文化、经典哲思与生活实践；
- 答题草稿自动恢复、提交请求幂等、超时友好提示、页面级错误重试；
- 标准/大字阅读模式，自定义悬浮底栏与“现代东方”视觉，不使用默认模板布局。
- 业务页全部使用微信原生 WXML 组件标签，首页底部展示运营主体与 APP 备案号。
- 开发版“我的”页提供受管理员验证保护的测试中心，可一键切换同一批10个测试学员；切换后首页、题目、提交、成绩、个人档案和榜单全部复用正式接口，体验版与正式版隐藏并拒绝该能力。

## 3. 联调中发现并修复的问题

真实 MySQL 启动时发现 Flyway 的 UUID 与手机号摘要使用 `CHAR`，而 JPA 模型按 `VARCHAR` 校验，导致启动失败。已统一为 `VARCHAR` 并重新完成 Flyway 建表和 Hibernate 校验。该问题只有真实数据库启动才能发现，现已修复。

管理端首次浏览器检查发现缺少 favicon 导致一个 404 控制台错误；已加入自定义印章图标，再次检查为 0 错误。

2026-08-07 上线终检发现 `miniapp/project.config.json` 存在孤立文本导致 JSON 无法解析，现已修复并把 JSON 解析失败纳入发布门禁。同时发现业务 WXML 使用了多种 HTML 风格标签，已全部替换为微信原生 `view/text` 并同步样式选择器；发布门禁现在会阻止同类问题再次进入候选版本。
